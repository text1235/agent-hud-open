## 版本保存规则

每项交付功能分别提交 Git；每个交付版本同步更新桌面程序、安装包和界面版本号，保存版本标签、对应提交、安装包校验和与更新内容。仅在实际安装并完成对应验收后标记已交付。按用户要求只保留当前安装包；回滚使用历史 Git 标签重新构建，不覆盖用户原始会话资料。
