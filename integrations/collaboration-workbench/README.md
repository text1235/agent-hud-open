# 协作工作台

当前服务版本 0.3.0（按额度选模型）；HUD 桌面客户端版本仍为 0.1.4。

本机地址：http://127.0.0.1:18500/ 。运行 `Z:\Hermes\启动协作工作台.ps1` 后打开 `Z:\Hermes\打开协作工作台.url`。

- Codex：当前聊天负责拆解、派工与独立验收。
- 大肥鱼：复用现有 Hermes 项目 Gateway，不替换微信及原任务交付机制。
- Antigravity：默认通过当前桌面服务的本机 API 创建原生会话，不再启动独立 `agy -p` 命令行。桌面未运行、项目或模型核验失败时明确报错，不回退 CLI。默认 `auto`，每次派工读取实时目录和额度。Argon High 余额高于 10% 时优先使用；余额 ≤10%、禁用或余额未知时切换到余额高于 10% 的可用模型，优先 3.8 Flash High。Argon 高中低档共享的余额不会被当成独立新额度。没有满足条件的模型时停止发送。支持显式模型 ID；指定模型不可用或低余额时同样选择替代，并在 model_selection 事件记录请求、实际模型、额度及原因。核对实际执行模型，不更换账号、不启用付费超额。

工作台提供项目列表、两端任务状态、交付结果及可用执行事件。Antigravity 任务记录保存所属项目、实际办公区、桌面会话 ID、原生项目 ID 和模型。只读取本工作台派发任务的响应和活动，不导入无关聊天，不记录认证参数、思考签名或调试系统提示。

网页手动提交的任务不会自动冒充 Codex 验收；如需完整验收闭环，从 Codex 聊天派工。工作台仅读取其他已有任务，不接管其他聊天的队列。第一版只在本机监听，不提供公网访问，不改变手机 VPN。公网部署前另加登录和持久入口。

派工的 `workspace` 默认填写实际项目根目录，工作台自动创建 `协作办公区\Antigravity\<任务ID>`。若已经分配办公区，可用 `workspace` 填该目录并通过 `project_root` 明确所属项目。桌面会话绑定项目根目录，提示词限定办公区输出；派工前核对原生项目资源路径，不使用最近创建项目或软件安装目录。

用户已授权今后的日常桌面派工：短期连接参数仅在本机内存中使用。桌面原生审批保留，需要授权时到 Antigravity 桌面确认。目录及任务边界不等于操作系统沙箱。

`completed` 仅表示桌面交付，Codex 仍需独立验收并记录 accepted/rejected。发送结果未知或连接中断时标记 uncertain；读取任务可恢复观察，不重新创建会话或重复发送提示词。重启工作台保留数据库与历史 CLI 任务。只正常停止空闲工作台，不强制终止桌面进程或其他客户端。
